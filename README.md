# 數位系統設計實習 - Final Project
## 深海潛艇：聲納盲航潛行

這是一款數位系統設計實習期末專題的 FPGA 遊戲。玩家駕駛潛艇穿越隨機生成的 64×64 雷區，依靠羅盤和有限的聲納找到安全路線，並在耐久耗盡前抵達終點。

## 遊戲特色

- **局部雷達**：8×8 LED 矩陣顯示潛艇周圍。水雷平時隱藏，發射聲納後才短暫顯現。
- **勝利畫面**：抵達終點時顯示視窗內所有水雷，再由外往內像聲納一樣收縮消失。
- **航行資訊**：七段顯示器顯示座標，羅盤燈指向終點，LCD 顯示耐久、剩餘道具、距離（到終點十字最近一格的步數）與近雷警告。
- **有限資源**：每局有 8 點耐久、9 次聲納，魚雷普通 6 發、困難 3 發。
- **隨機起點與終點**：每局起點和終點一起隨機產生，方向不固定。難度開關決定兩點距離與水雷密度。
- **洋流**：開啟後每 5 秒隨機選一個方向，整片雷區往該方向漂移一格（潛艇和終點不動），LCD 顯示 `CUR:N/S/W/E`。被推到潛艇身上的水雷算撞雷；終點周圍 5×5 保持無雷。

| 難度開關 | 起點到終點（DIST） | 水雷密度 | 魚雷 |
|---|---|---|---|
| 普通（OFF） | 24～48 格 | 約 1/16 | 6 發 |
| 困難（ON） | 64 格以上（最遠約 100） | 約 1/8 | 3 發 |

距離門檻是 `sonar_game_core` 的參數 `NORM_MIN_DIST`、`NORM_MAX_DIST`、`HARD_MIN_DIST`，魚雷數量是 `NORM_TORPS`、`HARD_TORPS`，射程是 `TORP_RANGE`，每格停留 `TORP_STEP_CLKS`（預設 30 clock = 60 ms），爆炸長度 `BOOM_CLKS`（預設 100 clock = 200 ms），都可自行調整（魚雷數量最多 7、clock 數最多 255）。起點周圍 5×5、終點周圍 5×5（`GOAL_SAFE`）保證沒有水雷。

## 操作方式

| 輸入 | 功能 |
|---|---|
| 上下左右按鈕 | 移動一格（按住不會連走；需按住約 120 ms 以上才確定被讀到） |
| LA 聲納 | 發射聲納：波紋擴散後全視野曝光約 2 秒（`SONAR_REVEAL`） |
| LA 開始 | 開始新局；遊戲中、勝利或失敗畫面按下都會重新開局 |
| 藍開關 難度 | 開局時鎖定，待機畫面 LCD 會即時顯示 `LV:NORM` / `LV:HARD` |
| 藍開關 洋流 | 待機畫面 LCD 顯示 `CUR:ON` / `CUR:OFF`；遊戲中可隨時開關 |
| LA 魚雷 | 按一下發射：魚雷以亮點沿船頭方向（最後一次移動的方向，開局預設朝北）直線飛行，每格約 70 ms、最多 4 格。撞到第一顆水雷時播放爆炸動畫（約 0.2 秒），水雷被清除；碰到地圖邊緣會停下。沒打中也會消耗，面向牆壁發射則不消耗。飛行中可以移動，但不能再發射下一發；按住不會連發 |
| 紅開關 Demo | 直接顯示視窗內所有水雷（展示、除錯用） |

## 開發平台

採用 Verilog-2001，目標板為 SMIMS VeriLite VLA-USB（第一代 Cyclone）。使用 Quartus II 編譯、ModelSim 驗證，並透過 VeriComm 與 VeriInstrument 操作。頂層模組為 `submarine_sonar_top`，主時脈預設 500 Hz（`CLK_FREQ = 500`）。

RTL 註解只用英文：舊版 Quartus II 以系統編碼讀檔，中文註解會變成 `???`。

接線與顯示設定請見 [腳位對照表](Docs/PINOUT.md) 和 [LCD 接線與時序](Docs/LCD_TIMING.md)。

## 模擬

在專案根目錄執行：

```powershell
.\Simulation\run_sim.ps1
```

會依序執行三個 testbench：

| Testbench | 內容 |
|---|---|
| `tb/tb_sonar.v` | 遊戲核心：隨機起點／終點範圍與方向、水雷密度與分布、安全區、移動、撞雷、聲納、魚雷、Demo、邊界、洋流四方向位移、勝利畫面、勝負 |
| `tb/tb_lcd.v` | LCD 腳位協定（500 Hz）：資料在 EN 高電位期間穩定、畫面內容、只在變動時重畫 |
| `tb/tb_game.v` | 以真實 500 Hz 時脈只透過 `inputs` 腳位玩完整局（自動駕駛找路），從腳位解碼矩陣、七段、LCD、LED 並與地圖比對 |

整局模擬的過程紀錄（地圖、路徑、矩陣畫面）會複製到 `Simulation/Reports/game_log.txt`。
