# 數位系統設計實習 - Final Project
## 深海潛艇：聲納盲航潛行

這是一款數位系統設計實習期末專題的 FPGA 遊戲。玩家駕駛潛艇穿越隨機生成的 64×64 雷區，依靠羅盤和有限的聲納找到安全路線，並在耐久耗盡前抵達終點。

## 遊戲特色

- **局部雷達**：8×8 LED 矩陣顯示潛艇周圍。水雷平時隱藏，發射聲納後才短暫顯現。
- **航行資訊**：七段顯示器顯示座標，羅盤燈指向終點，LCD 顯示耐久、剩餘道具、距離與近雷警告。
- **有限資源**：每局有 8 點耐久、9 次聲納與 1 發魚雷。玩家可選擇難度與目標區域，也可開啟洋流增加變化。

## 開發平台

採用 Verilog-2001，目標板為 SMIMS VeriLite VLA-USB（第一代 Cyclone）。使用 Quartus II 編譯、ModelSim 驗證，並透過 VeriComm 與 VeriInstrument 操作。頂層模組為 `submarine_sonar_top`。

接線與顯示設定請見 [腳位對照表](PINOUT.md) 和 [LCD 接線與時序](LCD_TIMING.md)。
