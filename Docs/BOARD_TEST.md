# 上板測試清單

依序進行，前面的項目確認無誤後再往下。時間都以 500 Hz 主時脈計算。

## 0. 設定

- [ ] VeriComm 主時脈設為 500 Hz（與 `CLK_FREQ` 一致）。
- [ ] 腳位依 [PINOUT.md](PINOUT.md) 指定；input8、input11～13 不需接。
- [ ] LCD 元件的 RST 指定到 output52。
- [ ] 七段使用 Seven Segment Select Mode 元件。

## 1. 開機待機畫面

- [ ] LCD 第一行顯示 `LV:NORM CUR:OFF`，第二行 `PRESS GO TO DIVE`，沒有亂碼或殘字。
- [ ] 矩陣中央亮一個 2×2 方塊。
- [ ] 七段顯示 X=32、Y=32（重置值）。十位在左、個位在右，沒有殘影。
- [ ] 板載 D0～D7 八顆全亮。
- [ ] 羅盤、綠、黃、紅、聲納燈全暗。

## 2. 開關極性（待機畫面測）

- [ ] 難度撥 ON → LCD 第一行變成 `LV:HARD`。
- [ ] 洋流撥 ON → 顯示 `CUR:ON`。
- [ ] 若顯示相反：把頂層參數 `SW_INV` 改成 0 後重新編譯（Demo 開關也會一起改）。
- [ ] 測完把兩個開關撥回 OFF。

## 3. 開局

- [ ] 按 GO：LCD 短暫出現 `GENERATING MAP`，接著變成 `HP:8 SON:9 T:6`（困難為 `T:3`）和 `DIST:0xx`。
- [ ] 普通模式開局時 DIST 介於 024～048；困難模式為 064 以上。
- [ ] 多按幾次 GO：每局起點座標都不同，羅盤指的方向也不同（不再總是左上）。

## 4. 矩陣方向（最重要）

開 Demo（紅開關 ON），讓視窗內的水雷顯示出來：

- [ ] 潛艇是固定亮著的那一點，位於左起第 4 欄、上起第 4 列。
- [ ] 按「右」：所有水雷往**左**移一格。按「上」：所有水雷往**下**移一格。
- [ ] 若左右相反，改 `MAT_COL_INV` 或對調 Col 接線順序；若上下相反，改 `MAT_ROW_INV` 或對調 Row 接線順序。

方向錯會讓玩家看著「旁邊安全」走過去卻撞雷，一定要先確認。

## 5. 移動與按鈕

- [ ] 按一下走一格；七段 X/Y 正確變化（上：Y−1，下：Y+1，左：X−1，右：X+1）。
- [ ] 按住 1 秒以上只走一格，不會連走。
- [ ] 很快的點擊可能沒反應（要按住約 120 ms 以上），記錄實際手感。
- [ ] 往羅盤亮燈的方向走，DIST 會減少。

## 6. 聲納

- [ ] 按聲納：聲納燈亮、SON 減 1，波紋由潛艇往外擴散約 1.2 秒，接著全視野顯示水雷約 3 秒，之後聲納燈熄滅。
- [ ] 聲納進行中再按一次：SON 不會減少。
- [ ] 用完 9 次後再按：沒有反應。

## 7. 近雷警告

- [ ] 潛艇周圍曼哈頓距離 2 格內（含斜角）有雷時，黃燈閃爍、綠燈熄滅、LCD 第二行顯示 `WARN: MINE NEAR!`。
- [ ] 離開後恢復綠燈和 DIST 顯示。

## 8. 撞雷

開 Demo 找一顆雷走過去：

- [ ] HP 減 1，板載 LED 少一顆，紅燈閃爍，矩陣閃爍約 0.4 秒。
- [ ] 閃爍期間按方向鍵或聲納會被忽略。
- [ ] 那顆雷消失，回頭再走同一格不會再扣血。

## 9. 魚雷（按鈕，input9）

- [ ] 待機時按魚雷鈕沒有反應；開局後 LCD 顯示普通 `T:6`、困難 `T:3`。
- [ ] 若一開局數字就自己減少，或按了都沒反應：按鈕極性不對，把 `TORP_LOW_ACTIVE` 改成 0（或 1）。
- [ ] 開 Demo，讓船頭方向（最後一次移動的方向；剛開局預設朝北）2～4 格外有一顆雷，中間沒有雷。
- [ ] 按魚雷鈕：亮點從船頭往前一格一格飛過去，撞到雷時出現「+」字再變成四個斜角的爆炸，之後那顆雷消失，`T` 減 1。
- [ ] 飛行速度：要快但看得清楚每一格。太快看不清楚就把 `TORP_STEP_CLKS` 調大（例如 45 ≈ 每格 100 ms），太慢就調小；爆炸太短或太長調 `BOOM_CLKS`。
- [ ] 飛行中可以照常移動；飛行中再按魚雷鈕沒有反應，`T` 不會減少。
- [ ] 同一直線上有兩顆雷：一次只炸掉比較近的那顆。
- [ ] 5 格以外的雷不會被炸掉，但魚雷仍會消耗。
- [ ] 按住不放：只發射一次。
- [ ] 用完後再按：沒有反應，`T:0`。
- [ ] 貼著牆壁、面向牆壁時發射：不會消耗魚雷。

## 10. 勝利與失敗

- [ ] **勝利**：走到終點「+」的任一格。因為十字的四個角也算，DIST 從 002 再走一步、或從 001 再走一步，都可能直接勝利。
  - 綠燈恆亮、羅盤熄滅、LCD 顯示 `MISSION CLEAR!!`，矩陣播放方框擴散動畫。
- [ ] **失敗**：HP 歸零。
  - 紅燈恆亮、板載 LED 全暗、LCD 顯示 `HULL BREACHED!!`，矩陣播放閃爍與叉叉動畫。
- [ ] 兩種動畫都會全亮閃爍，請以**燈號和 LCD** 分辨勝負。
- [ ] 勝利、失敗、遊戲中按 GO 都會重新開局，HP、聲納、魚雷回滿。
- [ ] 遊戲中切換難度開關不影響本局，下一局才生效。

## 11. 洋流

- [ ] 開洋流並開 Demo，原地停 20 秒：每 5 秒全圖隨機翻轉 1 格（有雷↔無雷）。因為全圖 4096 格，視窗內通常看不到變化，這是正常的。

## 12. 矩陣閃爍

- [ ] 平常只有少數列亮，每列更新率高。
- [ ] 最壞情況是 8 列全亮（聲納波紋、靠近地圖邊緣、勝負動畫），每列更新率只有 62.5 Hz。記錄是否看得到閃爍。

## 13. 長時間遊玩

- [ ] 連續玩數局（含困難＋洋流），沒有當機、畫面卡住或 LCD 停止更新。
